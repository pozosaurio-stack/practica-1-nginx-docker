## Texto para revisar y adaptar

Soy Pedro Pozo. Esta práctica trata sobre la creación de dos servidores web con Nginx y Docker. Una imagen proporciona la base, mientras que cada contenedor mantiene su propio entorno y sus archivos. Ambos servidores utilizan el puerto ochenta internamente. Para acceder desde el navegador, se publican en los puertos ocho mil ochenta y nueve y ocho mil noventa. El comando docker cp permite copiar el archivo index punto html al sistema anfitrión, editarlo y devolverlo al contenedor. Así, un servidor presenta información institucional y el otro información personal. La comprobación incluye revisar los contenedores activos, consultar las páginas y verificar una respuesta HTTP doscientos. También es necesario comparar el contenido recibido con el archivo local. Conservar copias y registrar los comandos ayuda a corregir errores y repetir el procedimiento. Estas ideas permiten comprender cómo publicar páginas estáticas en entornos separados.
